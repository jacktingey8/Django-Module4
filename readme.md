#  The circle

Surreal Social media app of the future, leave anonymous messages for other people to discover.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Open Terminal 
2. enter "python manage.py runserver"
3. Copy link http://127.0.0.1:8000/ into browser (VScodes embedded terminal dosen't work for some reason)

Instructions for using the software:

1. Move mouse to look for messages
2. double click to leave message
3. hold click over clear message to delete message
